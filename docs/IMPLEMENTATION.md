# 实施计划与验收台账

基准：根目录《PairShell-技术设计与开发规范》，完整范围保持不变。

1. 配对/授权：固定编码、HMAC 与私钥证明、邀请校验、单次领取、暂停及撤销竞争测试。
2. 审计：精确字节哈希链、落盘失败闭锁、回放导出、签名见证及可信密钥校验测试。
3. 传输：有界帧、序号去重、ACK/重传、路径指标与 Pion 适配，故障测试先于真实执行接入。
4. 执行：统一授权审计、任务去重、进程树取消、受控文件；SSH/MCP 固定绑定目标。
5. 产品接入：本机安全界面、merchant/customer/proxy/mcp/verify/replay CLI，协调服务器与部署配置。
6. 门禁：全量测试、静态检查、跨平台构建、依赖漏洞与许可清单；真实系统/网络/安全评审单列，不以本地通过替代。

各模块采用测试先行，接口小而明确；不提供绕过授权或审计的执行回退。协议代码在专项安全评审前不宣称可用于生产。

## 尚需外部验收

三系统真机、CGNAT/UDP 禁用/TURN TLS 网络矩阵、签名公证、独立密码与迁移专项评审、性能发布报告。

## 当前落地状态

已实现：双端 CLI、认证房间信令、身份绑定、客户同意/暂停/恢复/结束、控制租约、Pion 可靠流、序号迁移与双路径探测、SSH 固定密钥与原生 ProxyCommand、官方 MCP 七工具、独立任务/有界输出/请求去重、文件根目录与摘要写入、PTY/ConPTY、本机 HTTP 安全控制、审计事件与派生导出、见证签名注册与回执服务、部署与 CI 配置。

本地测试覆盖真实 TLS→配对→Pion→SSH→任务/远程 RPC 链路、暂停/撤销拒绝、日志校验，以及双 Pion 路径故障切换；不等价于生产网络验收。

## 完整版本尚未完成的工程项（不能标记为 v1 验收通过）

- 见证服务具备持久化签名 API，客户端尚未接入周期检查点、30 秒积压暂停、双方保存回执及最终清单签名闭环；CLI verify 当前只验证本地链和派生文件。
- 原生桌面已内嵌 xterm.js，商家 WebSocket 持续终端及客户本机只读镜像已接入；导出确认界面及未收尾日志启动扫描仍未完成。
- 直连与 relay-only 候选已并行准备并按 RTT 比较、切换；完整损耗/抖动策略、凭据定时刷新及跨网络矩阵仍需完善。
- Windows 独立任务暂以 taskkill /T 清理；ConPTY 使用 Job Object 但存在创建后纳管窗口。Unix 任务以进程组 KILL 清理，尚缺有界 TERM 宽限。取消完成须以最终任务状态为准。
- 文件 os.Root 防根目录逃逸、单次 1MiB 限制及摘要前置检查已实现；外部并发修改时 CAS、替换权限/ACL 保留及原子替换语义仍需平台专项加强。
- 审计逐事件同步保证先记录后操作；尚缺壁钟跳变事件、输出同步周期调优、磁盘配额、完整流式校验及 resize 派生回放。
- SSH exec 经过任务管理器，输出目前合并存储；exec stdin 未接入任务输入。系统信息与权限检测需扩充。
- 第三方依赖版本与许可文本已汇总；项目自身开源许可证需由维护者确定，发布签名、公证、SBOM/性能报告及专项独立审查未完成。

这些项目保留在完整交付范围内；当前二进制为开发构建，禁止把构建成功解释为上述要求已经满足。
