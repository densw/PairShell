# 0.9：统一应用与会话工作区

商家端和客户端融合为一个 PairShell。默认打开接受协助首页，点击“发起协助”切换；发起协助页有“接受协助”返回入口。当前会话结束后再切换，避免留下后台终端。

## 对应本次反馈

1. 客户协助页改为固定工作区；控制栏、返回和操作记录入口固定可见。去除页面、镜像外框和旧终端视口叠加滚动，仅保留终端历史滚动。两端终端使用窄圆角滑块。
2. 工具卡片改用 SVG 方向图标，浮层内用独立 SVG 关闭按钮，不再用旋转字符代表关闭。
3. 邀请文本框不可拖拽缩放，不显示右下角拖拽柄。
4. 固定 14 位数字采用两排分格；保留一个真实输入控件，支持一次粘贴、全角数字转换、键盘编辑及按格定位。长度错误不发起连接，不会静默截断长码。
5. 操作记录移入原生模态面板并分页，中文按显示宽度换行；每页可完整读取，无需再嵌套滚动。
6. 引导令牌已使用时先核对现有认证 Cookie；无效时展示返回配对入口。可信返回地址通过启动片段带入并保存在当前历史状态，重载后仍可恢复。返回时重置旧会话，授权不复用。

客户镜像保留远端 PTY 行列和 ANSI 数据，按窗口缩放整个网格；不会改变远端 Shell 尺寸，也不创建第二个终端。小窗口文本会相应缩小，放大窗口可改善阅读。客户无法发送终端输入。

## 实现与验证

主要变更：`internal/uiassets/control.html`、`control.js`、`terminal-view.js`、`merchant.html`、`merchant.js`、`ui.css`、`terminal-assets/workspace.css`；`cmd/pairshell/main.go` 携带恢复地址；原生窗口命名和双平台打包脚本统一为一个入口。

- 全量固定路径 Go 测试和 `go vet ./...` 通过。
- 12 组 Node 行为测试通过，包含新增镜像网格缩放、令牌恢复、分格输入和中文记录分页测试。
- 浏览器 640×480、866×660 下，客户工作区无页面溢出，商家默认侧栏内容同高；大量连续输出仅在终端内滚动，滚轮检查确认滑块位置变化。
- Windows 同一个 PairShell.exe 的两个角色原生布局检查通过。
- 无新增依赖。统一已有能力和入口，去掉重复应用副本、字符箭头及嵌套页面滚动。

界面截图使用本机隔离示例，没有自动授权真实远程会话。完整跨网络人工操作验收及 Intel Mac 实机运行尚未完成；Mac 包为 ad-hoc 开发签名，未做 Apple 公证。

终端样式核对参考 [xterm.js 官方样式](https://github.com/xtermjs/xterm.js/blob/master/css/xterm.css)；项目仍使用已锁定的内嵌发行文件，没有新增或升级终端依赖。

Mac 统一安装包仅含一个 PairShell.app；严格签名校验、DMG 校验、两个角色三种尺寸原生布局检查均通过。回传文件 SHA-256 与远端一致；Windows ZIP CRC 及单一启动入口检查通过。
