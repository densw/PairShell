# PairShell 功能与交互清单

核对日期：2026-11-20。依据当前入口、授权门、执行器、传输及原生壳代码；不把构建成功当作生产验收。

| 功能 | 商家端 | 客户端／限制 |
|---|---|---|
| 原生桌面窗口 | Windows WebView2、macOS WKWebView | 同一个 PairShell 内切换双角色，离线资源，无需浏览器 |
| 设备码配对 | 12 位单行分组输入、整串粘贴、Enter 连接 | 自动出码、复制、刷新、过期重试 |
| 邀请配对 | 高级入口创建邀请 | 高级入口粘贴邀请，核对校验码 |
| 身份核对 | 配对绑定临时身份、核对码 | 客户确认后才授予能力 |
| 持续终端 | 一个 SSH PTY；方向键、补全、中断、粘贴、缩放 | macOS 原生 Shell／Unix PTY、Windows PowerShell／ConPTY |
| 目录与输出 | 提示符由远端 Shell 生成，ANSI 输出保留 | 真实目录、交互程序与输出，不按命令逐条确认 |
| 终端观看 | 商家操作 | 客户只读观看同一 PTY；保留尺寸、颜色、光标，缓冲有界 |
| 控制会话 | 取消连接、结束、同窗口重新配对 | 允许一次、暂停新输入、恢复、结束；结束撤销旧授权 |
| 链路 | 并行直连／中继候选、按 RTT 选优及探测切换 | 头部展示当前链路、RTT 与文字质量提示；不承诺所有 NAT 均能直连 |
| CLI | connect、shell、merchant、proxy | host、customer、config；headless 接入适配器 |
| MCP | stdio，会话绑定 | session_info、task_start/status/output/cancel、file_read/write 七工具；一次完整协助授权 |
| 独立任务 | 启动、状态、分页输出、取消、请求去重 | 可与持续终端同时使用，保留任务资源上限 |
| 文件工具 | 受保护会话调用 | 真实路径、远程当前账号权限、大小限制、写入前摘要检查 |
| 本机审计 | 输入意图、输出与控制事件 | 本地哈希链、任务／终端记录、verify 校验、转义 replay 回放 |
| 见证服务 | 签名注册／回执服务 API | 客户端周期检查点和最终签名闭环仍未接完 |
| 历史记录 | 两端首页查看，滚动输出 | 搜索、新增备注、编辑标题／备注、回收站删除与恢复，原始日志只读 |
| 服务配置 | 自定义地址默认空、强制自定义选项 | 官方尚未开放；可用时作兜底，不转发自建部署令牌，不绕过证书验证 |
| 服务端 | 协调／认证信令／设备码信箱／限额／TURN 配置 | Docker 部署；短码服务须运营者显式启用 |
| 本机安全 | 受保护会话引用、来源与窗口令牌检查 | 回环绑定、Cookie／CSRF、能力检查；MCP 不能替客户同意 |
| 发布包 | Windows 安装／卸载 EXE、双角色入口、便携 ZIP | macOS 单一通用 App ZIP，首页切换角色，可复制到其他 Mac |

## 本轮交互重新组织

客户首页只有一个主任务：分享配对码。生成、等待、错误分别有明确反馈；邀请与服务器放在可展开设置中。授权页先核对对象，再解释本次能力；授权后切换为只读终端与暂停／结束控制，操作记录按需展开。

商家连接前突出配对输入和恢复指引；连接中禁止重复提交并立即反馈；终端真正就绪后收起连接面板。头部集中显示连接、链路、延迟和结束入口。手动展开面板不会被轮询强制收起。断开后保留可用的重新连接入口。

设计采用同一套深色工具界面：14px 系统正文字体、清晰对比、40px 操作控件、统一焦点样式、蓝色主操作、绿／黄／红状态并附文字。Mac 与 Windows 保留各自原生窗框、系统字体和常用复制快捷键。无网络字体和新依赖。

## 明确待验收

生产发布前仍需独立安全审查、CGNAT／禁 UDP／TURN TLS 的跨网络矩阵、进程纳管窗口与文件原子替换专项、审计配额与完整见证闭环。Mac 开发安装包采用 ad-hoc 签名，尚无 Developer ID 公证；不能称为免 Gatekeeper 提示的正式发行版。
