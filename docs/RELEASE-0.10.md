# 0.10：一行配对码与真实阶段动效

配对区从两排 14 格改为单行三个四位组，新生成配对码为 12 位。使用一个真实输入控件保留粘贴、键盘编辑和选择，避免多个输入框间跳焦点。

## 动效设计

| 真实阶段 | 品牌图标表现 |
|---|---|
| 等待连接 | 蓝、青括号轻微呼吸，终端光标渐亮 |
| 建立配对 | 括号靠拢，三点传递，外环缓慢旋转 |
| 核对身份／等待授权 | 中心显示金色锁，外环低频呼吸 |
| 打开终端 | 返回终端提示符，外环稍快旋转 |
| PTY 就绪 | 绿色品牌勾短暂出现，同时进入终端 |
| 失败 | 红色断链标记，单次轻微反馈，显示重试入口 |
| 已结束／终端关闭 | 静态暂停标记，取消持续旋转 |

图标为原有 PairShell 品牌的代码原生 SVG，使用 CSS 动效，无新增依赖。动效由 `renderJourney()` 的真实阶段驱动，不依赖 animationend，不引入等待时长，不显示虚构百分比。尊重 prefers-reduced-motion；减少动态效果时保留静态图形、颜色和状态文字。

## 配对协议与升级

新码仍为六位公开定位符，加六位均匀随机 PAKE 秘密；视觉按四位分组，解析仍按六位分割。沿用现有服务端接口，无需重新部署。随机秘密从八位降到六位（约 19.9 位熵）；单次原子领取、五分钟有效期、限流、PAKE 和客户本机确认仍然必要，定位符不能计入秘密强度。

新版可输入旧版 14 位码；旧版不能输入新生成的 12 位码，发起方和接受方请一起更新。未增加静默自动重试或复用旧授权。
