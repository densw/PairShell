# 终端交互与客户观看

本轮目标：商家连接后专注终端，客户能观看同一终端，用户随时知道连接状态并能结束协助。

主要修改文件：`internal/terminal/shell.go`、`pty_unix.go`（默认 Shell 与提示符）；`internal/uiassets/merchant.html`、`merchant.js`、`terminal-assets/workspace.css`（商家专注界面）；`internal/executor/terminal_view.go`、`terminal.go`、`internal/localui/server.go`、`internal/uiassets/terminal-view.js`、`control.html`、`control.js`、`ui.css`（客户只读观看）；`cmd/pairshell/main.go`（接线和结束画面保留）。相关 Go 与 Node 回归测试随同新增。

## 实现选择

- 继续使用已内嵌的 xterm.js 和原生 PTY。提示符由远程 Shell 生成，目录随 `cd` 更新；不在界面中猜测或伪造目录。
- 商家收到 PTY 就绪后自动收起连接面板，头部保留面板开关与结束连接。失败或结束时恢复配对入口。
- 头部连接状态旁集中显示直连／中继和 RTT。小于 80ms 绿色，80–200ms 黄色，大于 200ms 红色；未知灰色，均带文字，颜色表示交互延迟而非安全程度。
- 客户授权后，以只读终端作为主画面，暂停／恢复输入和结束协助保留在明显位置。PTY 的输出字节与尺寸由本机内存缓冲直接提供，150ms 轮询读取，不扫描整份审计文件。
- 仅同步 PTY 输出，不把原始键盘输入重新回显，因此密码等关闭回显的输入不会被额外显示。用户仍能在正常终端输出中看到命令及其结果。

曾考虑直接把审计文本当作终端，以及启动第二个观察 Shell。前者丢失画面尺寸且需要频繁扫描文件，后者与商家实际会话不一致，均不采用。

## 边界

观看接口沿用本机会话认证、来源和 Host 检查，仅允许 GET，没有输入或调整远端终端尺寸的能力。客户 xterm 禁用输入，不创建 SSH Shell、不转发键盘。

实时内容保留有界缓冲；落后时明确标记只显示最近内容，完整操作记录仍在本机审计中。观看终端按商家实际行列渲染；较窄窗口可以滚动，不改变远端终端尺寸。暂停阻止新输入，已运行程序仍可输出。

结束时立即撤销授权、清理终端；桌面本地观看接口最多继续保留两分钟，以便读取尾部输出及显示结束状态，不保留执行能力。观看端有界读取最终分页，再停止同步。窗口退出后后台进程结束。

## 验证项目

- Shell 目录提示符及 `cd` 后变化，用户配置保持完整。
- 商家自动收栏、手动开关、结束／失败恢复，RTT 分级与未知状态。
- 客户输出字节、ANSI 颜色、光标、终端尺寸一致；只读、分页、截断说明、暂停和结束。
- 认证与跨来源拒绝、POST 拒绝、会话隔离；已有重连与授权撤销回归。
- 原生 Windows／Mac 启动和布局，最终安装文件与构建摘要一致。
