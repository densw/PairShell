# 0.7.1：配对首页高度修复

修复默认窗口与 Windows 150% 缩放下，客户配对首页出现不必要的页面滚动条。

原因是首页使用较大的顶部留白、卡片间距，以及两个纵向设置折叠入口；此前布局检查只限制横向溢出，未限制首页总高度。

本次压缩配对页的冗余留白；邀请和服务器设置改为并排入口；按窗口高度减少辅助信息占位，不缩小主要操作字体、不用 overflow:hidden 裁剪页面。展开设置时，页面仍可正常滚动。

验证：

- 实际 Windows 原生 WebView2 默认窗口测得 CSS 视口 866×663，文档宽高也是 866×663，`WINDOW_LAYOUT_READY`。
- 浏览器布局检查 920×720、866×660、700×550、640×480 均无横向／纵向溢出；设置展开后可滚动，收起后恢复完整首页。
- Mac 原生布局测试增加纵向完整性断言；920×720、700×550、866×660 三个视口均通过，文档高度等于视口高度。
- 配对／重连行为、提交防重、商家收栏、对比度和静态检查通过。

交付文件：`PairShell-0.7.1-Windows-x64.zip`、`PairShell-0.7.1-macOS-universal.dmg`。Mac 仍为开发签名、未公证安装包，供用户手动安装。
