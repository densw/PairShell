# 0.8：连接流程、分色与返回重连

## 主要交互

- 邀请连接、服务器配置、CLI/MCP 改为带图标、说明和分色的紧凑卡片。同组只展开一项；服务器地址可直接识别，创建令牌移到邀请入口中。
- 配对使用蓝色，服务器配置青色，邀请紫色；等待黄色、就绪绿色、失败红色，始终附文字说明。
- 连接过程分为“配对设备→客户授权→打开终端”。收到实际 PTY ready 后才收起面板、淡出引导并聚焦终端。动效不阻塞输入，支持 reduced-motion。
- “连接与工具”恢复侧栏；“结束并重新配对”先结束旧会话，清除已消耗的配对码并聚焦输入。结束请求失败时仍有明确的终端恢复入口。
- 客户进入授权页前有交接提示，迟到回调不能覆盖新配对；授权页先读取真实状态，避免短暂显示错误的操作界面。
- 客户可“结束并返回配对”；结束后以返回配对为主要入口，继续保留已同步终端画面。返回地址仅接受本机根页面，并强制重置旧会话。

## 验证

- 全量固定路径 Go 测试及 `go vet` 通过。
- 八组 Node 行为测试通过：重连、商家收栏、只读镜像、提交防重、设置换码、连接阶段、客户返回及交接代次隔离。
- 五个平台构建通过。Windows 包内后端与验证构建一致，ZIP CRC 通过。
- Windows 商家端、客户端实际原生窗口均为 866×663 视口、文档同高，没有页面溢出。客户首页保留 0.7.1 高度适配。
- Mac Universal 包两个角色严格签名校验、原生启动检查通过；920×720、700×550、866×660 三种尺寸均无页面横向或纵向溢出。安装包已回传并核对 SHA-256；Intel 包含在通用包中，未在 Intel 实机运行验收。

主要文件：`internal/uiassets/merchant.html`、`merchant.js`、`terminal-assets/workspace.css`、`invite.html`、`desktop.js`、`control.html`、`control.js`、`ui.css`；新增连接／返回／跳转行为测试，扩展 Mac 原生只读布局检查。
