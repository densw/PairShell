# 0.8.1：配置不再撑长连接侧栏

截图中的滚动条来自侧栏内展开服务器配置，造成顶部内容滚出视野。本次把商家端的邀请、服务器配置、CLI/MCP 改为独立浮层，保留原有字段与分色，关闭后返回原入口。

- 点击背景、完成并返回或 Esc 可关闭；Tab 焦点保持在面板内。
- 终端就绪收起侧栏时，同时关闭工具浮层，避免遮住终端。
- 默认连接侧栏不显示滚动条；极小高度仍保留滚轮和触控板滚动能力。终端历史滚动保持可用。
- 866×660 下侧栏高度与内容高度均为 592；三个工具面板均完整容纳内容。700×550 下侧栏高度与内容高度均为 482，邀请面板为 444，没有截断内容。
- 四组商家端行为测试与对比度检查通过；Windows 原生默认窗口布局检查通过。截图是本机隔离界面示例。

改动文件：`internal/uiassets/merchant.html`、`merchant.js`、`terminal-assets/workspace.css`、`scripts/test-connection-journey.cjs`。未新增依赖，未修改配对权限规则。
