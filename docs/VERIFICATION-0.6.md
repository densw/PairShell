# 0.6 产品简化验证

日期：2026-11-19。

- 终端复用 xterm.js 6.0.0 / FitAddon 0.11.0，固定资源、许可证和 SHA-256 清单内嵌；不使用 CDN。独立 Windows WinForms/WebView2 客户端实际启动，并通过本机窗口截图检查主界面；无需用户浏览器。
- 真实 TLS 协调服务 → 客户设备码 → PAKE → 延迟客户授权 → Pion → SSH → 本地 CLI → 暂停/撤销拒绝 → 审计收尾的端到端测试通过。测试未给客户端服务器管理员令牌。
- 真实 SSH/WebSocket 测试验证 Enter、Ctrl+C、方向键、Tab、中文和 resize；WebSocket 验证 Host、Origin、首帧窗口能力令牌，不在 URL 传终端能力。
- 官方默认地址及自建配置的验证、优先级、原子保存与 Windows 用户权限测试通过。
- 全量 go test、go vet、JS 语法检查通过；govulncheck 未发现已知漏洞。PAKE 与传输仍须独立安全审查，扫描不能代替审查。
- 旧邀请与自动设备码监听竞争的回归测试通过；旧邀请只能启动一次会话。
- 安全复核修复了匿名设备码隐式绕过私有创建令牌的问题：默认关闭匿名设备码注册，仅以 `-device-pairing` 显式启用，私有实例回归测试通过。
- 一次集成测试暴露客户结束后等待控制租约轮询导致清理延迟。已新增独立撤销监测并进行回归与重复测试，不以延长测试超时代替修复。

本地到官方公网9443端口超时；经现有 SSH 通道在服务器本机使用有效 TLS 检查 /healthz 返回 ok，服务 active。未改生产服务器服务配置或部署生产更新。新短码服务端二进制已随源码构建，实际使用短码前须升级服务端。

当前构建机是 Windows。Windows 独立客户端已打包；Linux/macOS Go 客户端与服务端为交叉编译结果，不等于其原生窗口及快捷键真机验收。macOS 新版 DMG 需要在 Mac 上构建，不能把原0.5.1 DMG 解释为0.6版本。

当前桌面壳沿用本地内嵌组件，安装包体积未作减小承诺。CLI raw mode 恢复由 defer 保证；Windows/macOS 的 IME、vim/top、剪贴板系统权限及休眠/断网仍需真机扩展矩阵。
