# 连接过程与返回入口（0.8）

本轮保留原生壳、临时配对和授权边界，调整交互层。

- 配对为主操作，蓝色；服务器配置青色；邀请与 CLI/MCP 紫色；等待黄色、已就绪绿色、失败红色，同时保留文字。
- 左侧高级入口改为带说明的紧凑卡片，点击时才展开；同组一次展开一项。切换角色独立放在底部，连接期间隐藏，避免误离开。
- 右侧按配对、授权、打开终端三个真实阶段反馈。仅收到 PTY ready 后淡出引导、收起左栏；终端始终直接接受输入，不依赖动画完成事件。
- 头部“连接与工具”可恢复侧栏；“结束并重新配对”先结束旧会话，再清空已消耗的配对码、返回输入，不自动连接或重放命令。
- 客户从出码页进入授权页时显示交接状态，并核对连接代次，迟到跳转不能覆盖新配对。
- 客户控制页可明确“结束并返回配对”；结束后以重新配对为主入口，已撤销的旧授权不能恢复。
- 动效仅使用 opacity／transform，尊重 reduced-motion；默认首页继续满足高度适配。

验收重点：状态过渡、旧回调隔离、终端就绪、结束后清理、返回重连、配置保存反馈和小窗口完整性。
