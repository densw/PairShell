# PairShell 桌面交互设计

用于 Windows／macOS 的商家端、客户配对和授权／观看页面。

ui-ux-pro-max 的检索已确认：Dark Mode 风格适用于编码工具；Error Recovery、Submit Feedback、Contextual Live Badge Updates 指导状态和重试。检索返回的营销落地页结构不适合桌面终端，未采用。

- 背景 #10161f；面板 #19222e；边界 #354356；正文 #eff4fc；次要文字 #b0bed0。
- 主操作 #426bd0 配白字；成功 #6cdbc0；等待 #efc779；危险 #ffadb5。状态同时有文字，颜色不表示安全保证。
- 系统 UI 字体 14px、1.6 行距；标题 24–28px；终端使用系统等宽字体，字体完全离线。
- 空间以 4／8px 为基准，面板间距 24px，按钮 40px；明显焦点和完整键盘操作。
- 客户配对：共享代码为视觉中心，安全与观看说明为辅助。一次授权后切换为只读终端。
- 商家：连接前配对面板与空状态；操作时全宽终端，连接设置按需恢复。
- 反馈：立即提交态、就近错误、保留输入、明确恢复入口；不自动重放命令。
- 动效只用于短暂颜色变化；尊重 reduced-motion，不引入装饰动画或新库。

## 0.9 会话工作区补充

- 单一应用、双角色入口；进行中的会话结束后再切换。
- 协助页禁止纵向堆叠终端与审计记录。控制区固定，终端占满剩余高度，操作记录改为模态分页。
- 终端仅保留一套历史滚动控件：窄圆角滑块、透明轨道；全局表单样式不得影响 xterm 隐藏输入层。
- 工具入口用 SVG 右箭头表示打开浮层，浮层用独立 X 关闭；不用字符旋转表示关闭。
- 配对码为 14 位，视觉分格与单一真实输入结合，保持粘贴、选择和键盘编辑。
